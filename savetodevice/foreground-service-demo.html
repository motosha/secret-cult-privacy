SaveToDevice: local file import and export

Google Play permission review demonstration for pt.sundust.savetodevice, version 1.4.0 (version code 5).

Open or download the MP4 directly

  1. The user starts saving a shared file and chooses its destination in Android's document picker.
  2. While the app is in the background, a foreground notification displays the ongoing copy's progress.
  3. Returning to the app shows the transfer and its successful result.

The app uses FOREGROUND_SERVICE_DATA_SYNC for the user-initiated local import/export operation. Large files and slow document providers must continue to copy when the user leaves the activity. Progress and cancellation are available while the operation runs. The service stops when the operation completes or is cancelled. It does not perform scheduled or hidden network synchronization.

This is an unedited Android Emulator screen recording of the signed release build. The harmless 16 MiB demonstration file is streamed slowly by a separate test-only document provider so that the real background progress remains visible. That provider is not included in the published app. No personal data is shown.
